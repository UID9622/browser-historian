# 贡献指南

感谢你有兴趣为本项目做出贡献！我们欢迎所有形式的贡献。

## 如何贡献

- Bug 报告：使用 Issue 模板
- 功能建议：使用功能请求模板
- 代码提交：Fork → 新建分支 → 提交 PR

### 提交规范

遵循 [Conventional Commits](https://www.conventionalcommits.org/zh-hans/)：`feat`、`fix`、`docs`、`refactor`、`test`、`chore`

## 开发环境

```bash
git clone https://github.com/UID9622/browser-historian.git
cd browser-historian
npm install
npm test
```
