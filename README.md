## 简介

浏览器史官是龍魂体系的浏览器历史管理工具，包含三大组件：
1. **Chrome 扩展** — 浏览器内智能分类 + 防线状态面板
2. **本地采集器** — 底座痕迹四维采集 + 四道安全防线
3. **复原引擎** — AI痕迹复原

所有数据默认本地存储，不传云端。
