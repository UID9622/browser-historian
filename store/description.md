# Chrome Web Store — 扩展描述

## 名称
龍魂 · 浏览器史官 (Longhun Browser Historian)

## 短描述 (132字符以内)
浏览器历史智能分类 + 四道安全防线(网络阻断/恶意过滤/设备加密/导出签名) + AI痕迹复原。数据不出设备，主权归你。

## 详细描述

### 你的浏览器历史，你自己做主

龍魂 · 浏览器史官是一个完全本地运行的浏览器历史管理工具。它将你的浏览历史按17个分类自动归类，并内置四道安全防线，保护你的数字痕迹不被窥探。

### 核心功能

**智能分类**
- 自动将浏览历史归入17个类别（技术、新闻、社交、购物、娱乐等）
- 本地分类，无需联网
- 支撑浏览器历史的时间线可视化

**四道安全防线**（需配合本地采集器）
1. **网络守卫** — 强制防火墙阻断可疑境外IP
2. **恶意过滤** — URLhaus动态威胁情报 + 未知可执行文件默认拒绝
3. **设备金库** — AES-256+CBC硬件绑定加密
4. **导出签名** — HMAC-SHA256三重绑定防篡改

**AI痕迹复原**（需配合自建复原引擎）
- 从本地痕迹反向重建用户行为时间线
- 导出专业签名报告
- 一切在你自己设备上完成

### 我们的承诺

- **零数据上传**: 你的浏览记录不离开你设备
- **开源透明**: 完整源码可用，安全可审计
- **数据主权**: 你拥有你的数据，不是平台
- **无追踪**: 不集成任何分析/统计SDK

### 本地采集器

浏览器史官的完整功能需要配合本地采集器（Python脚本）。采集器提供四道防线和痕迹采集能力。
安装包内含采集器，详见 README。

### 隐私

完整隐私政策见扩展内或安装包 `store/privacy-policy.md`。
