# Chrome Web Store 截图要求

需要准备以下截图（1280x800 或 640x400，PNG格式）：

1. **screenshot-1.png** — 主弹窗：分类历史列表 + 防线状态面板
2. **screenshot-2.png** — 搜索过滤 + 分类筛选
3. **screenshot-3.png** — 防线详情：四道防线展开状态
4. **screenshot-4.png** — 导出功能：签名导出对话框
5. **screenshot-5.png** — 设置面板

截图方法：
1. 在 Chrome 中加载扩展（chrome://extensions → 加载已解压的扩展）
2. 点击扩展图标打开弹窗
3. 使用 Chrome DevTools 截取弹窗区域（或截图整个屏幕后裁剪）
4. 放到此目录，命名为 screenshot-1.png ~ screenshot-5.png
